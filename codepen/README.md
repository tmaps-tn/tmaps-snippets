# TMaps examples on CodePen

The same examples as the [live demos](https://examples.tmaps.tn/), reduced to one HTML, one CSS and one JS panel so you can fork and edit them in the browser.

| Example | Library | Pen |
|---|---|---|
| [Map with Leaflet and raster tiles](01-leaflet-raster/) | Leaflet | [Open on CodePen](https://codepen.io/tmaps/pen/KwWBabZ) |
| [Vector map, 4 styles and 3D tilt](02-maplibre-styles/) | MapLibre GL | [Open on CodePen](https://codepen.io/tmaps/pen/yyMqgGK) |
| [OpenLayers map with a shareable view](03-openlayers-share/) | OpenLayers | [Open on CodePen](https://codepen.io/tmaps/pen/zxZLNyy) |
| [Address search in French, Arabic and Arabizi](04-address-search-arabizi/) | Leaflet | [Open on CodePen](https://codepen.io/tmaps/pen/vExagbN) |

Each folder holds the three panels of a pen (`index.html`, `style.css`, `script.js`). To run one in your own pen, replace `YOUR_API_KEY` in `script.js` with a key from the [TMaps console](https://app.tmaps.tn) and add `cdpn.io` and `codepen.io` to its authorized domains (the CodePen preview runs on cdpn.io).
