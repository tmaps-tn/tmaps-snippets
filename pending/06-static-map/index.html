Static map image

Turn a place or a route into a map image for a property listing, an order confirmation email or a PDF report. The TMaps Static Maps API returns a PNG from a plain URL: the page that shows it needs no map library.

Pick a place, or click the map to move the pin.

Drag the A and B markers, or click the map to move B. The image is framed on the route automatically.

How it works

        
    
          
  1. Listing thumbnail: GET /maps/static with center, zoom (1 to 20) and size, plus a marker written lat,lng|color|label.
    2. 
          
  2. Route thumbnail: the page first calls GET /routing/direction. Its geometry is an encoded polyline (precision 5) that goes straight into path=weight:5|color:0x2e47f0|enc:….
    3. 
          
  3. Without center and zoom, the image is framed on the markers and paths, with a padding of 40 px by default.
    4. 
          
  4. The page fetches the image first so an error is shown as text, then displays it. On your site, put the URL in an <img> tag, an email template or a PDF generator.
    5. 
        

        
Good to know

        
    
          
  • Up to 1280 × 1280 pixels. scale=2 doubles the pixels for retina screens.
    • 
          
  • format is png (default), webp or jpg. lang=ar shows the labels in Arabic.
    • 
          
  • enc: is always the last part of a path and the polyline must be URL-encoded. Repeat marker (up to 50), path or polygon=fillcolor:0x2e47f033|lat,lng|… (up to 20 each).
    • 
          
  • bbox=minLng,minLat,maxLng,maxLat shows a whole area. For long routes, send a POST with a JSON body (markers, paths with polyline, coordinates or geojson) to keep the URL short.
    • 
          
  • Errors are JSON, e.g. {"error": {"code": "INVALID_REQUEST", "message": "…"}} with status 400. The URL fully describes the image, so cache it on your CDN.
