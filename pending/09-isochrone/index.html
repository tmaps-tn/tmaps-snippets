Delivery zone with isochrones

See which area a restaurant, a store or a warehouse can reach in 5, 10 and 15 minutes. The TMaps Isochrone API returns the reachable zones as GeoJSON polygons. Click the map to move the starting point.

Click the map to calculate the zones from another point.

    API request 
    POST https://api.tmaps.tn/routing/isochrone?api_key=YOUR_API_KEY

    How it works

    1. The page sends POST /routing/isochrone with an origin and a list of contours, each one { time: minutes } or { distance: km }.
    2. The response is a GeoJSON FeatureCollection with one polygon per contour, in the order requested.
    3. The largest zone is drawn first so the smaller ones stay visible on top.

    Good to know

    • Up to 4 contours per request, 60 minutes or 50 km each.
    • The optional colors array is echoed back in each feature's properties.color, ready for styling.
    • Typical uses: delivery zones, retail catchment areas, "schools within 10 minutes" for real estate, emergency coverage.
