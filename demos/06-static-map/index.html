Static map image

Generate a PNG image of a map with markers, ready for emails, PDF reports or listing thumbnails. Pan the interactive map to choose the area, click to move the marker, then generate the image with the TMaps Static Maps API.

API request 
GET https://api.tmaps.tn/maps/static?center=36.8528,10.3261&zoom=15&size=800x500&style=streets&marker=36.8528,10.3261|red|A&api_key=YOUR_API_KEY

How it works

  1. The image is a plain URL: GET /maps/static with center, zoom and size.
  2. Each marker parameter adds a pin, written lat,lng|color|label. Repeat the parameter for several markers (up to 20).
  3. Put the URL in an <img> tag, an email template or a PDF generator.

Good to know

  • Maximum size is 1280 × 1280 pixels. Only PNG is supported for now.
  • Use bbox instead of center + zoom to fit an area automatically.
  • Draw a route with path=weight:5|color:0x0066ff|enc:… using the encoded polyline returned by the Directions API.
  • The URL fully describes the image, so cache it on your CDN to avoid generating it twice.
