Plus Code from a map click

Click anywhere on the map. The TMaps API turns the GPS coordinates into a Plus Code, a short address such as 8F8GR54J+JJ that you can share, print on a delivery slip or paste into Google Maps, even where there is no street name.

Click the map to get the Plus Code of a point. The rectangle is the area the code covers.

API request 
GET https://api.tmaps.tn/geocoding/pluscode?lat=36.806500&lng=10.181500&zoom=18&api_key=YOUR_API_KEY

How it works

  1. A click on the map gives a latitude and longitude.
  2. The page sends GET /geocoding/pluscode with lat, lng and zoom, which sets the precision of the code.
  3. The API returns plus_code with the lat and lng it encoded. The page draws the cell of the code: every point in that rectangle has the same Plus Code.

Good to know

  • zoom maps to the code length: up to 14 gives 8 digits, up to 18 gives 10 digits (about 14 m, the usual precision), above 18 gives 11 digits (about 3 m). Without zoom the code has 14 characters.
  • Plus Codes are an open standard (Open Location Code): they work offline, in Google Maps and in any app that supports them, with no account.
  • You can also send zoom, x and y of a map tile instead of lat and lng: the API returns the 10 digit code of the tile center.
  • Reverse geocoding results also carry a plus_code, with a short form next to the delegation name.
  • Typical uses: delivery to homes with no street number, rural sites and farms, meeting points, field inspection reports.
