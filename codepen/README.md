# TMaps examples on CodePen and JSFiddle

The same examples as the [live demos](https://examples.tmaps.tn/), reduced to one HTML, one CSS and one JS panel so you can fork and edit them in the browser.

| Example | Library | CodePen | JSFiddle |
|---|---|---|---|
| [Map with Leaflet and raster tiles](01-leaflet-raster/) | Leaflet | [Open on CodePen](https://codepen.io/tmaps/pen/KwWBabZ) | [Open on JSFiddle](https://jsfiddle.net/Tmaps/8wyrz5j9/) |
| [Vector map, 4 styles and 3D tilt](02-maplibre-styles/) | MapLibre GL | [Open on CodePen](https://codepen.io/tmaps/pen/yyMqgGK) | [Open on JSFiddle](https://jsfiddle.net/Tmaps/1ej8bg92/) |
| [OpenLayers map with a shareable view](03-openlayers-share/) | OpenLayers | [Open on CodePen](https://codepen.io/tmaps/pen/zxZLNyy) | [Open on JSFiddle](https://jsfiddle.net/Tmaps/vw0smpe6/) |
| [Address search in French, Arabic and Arabizi](04-address-search-arabizi/) | Leaflet | [Open on CodePen](https://codepen.io/tmaps/pen/vExagbN) | [Open on JSFiddle](https://jsfiddle.net/Tmaps/dt4scn98/) |

Each folder holds the three panels of a pen (`index.html`, `style.css`, `script.js`). To run one in your own pen, replace `YOUR_API_KEY` in `script.js` with a key from the [TMaps console](https://app.tmaps.tn) and add the playground's domain to its authorized domains: `cdpn.io` and `codepen.io` for CodePen (the preview runs on cdpn.io), `fiddle.jshell.net` for JSFiddle (the result runs there).
